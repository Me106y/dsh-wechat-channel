## 接入核验

- [ ] G1：记录实际 DSH/Node/平台，验证服务和扩展点。
- [ ] G2：验证登录身份、稳定消息 ID、媒体、上下文和发送重试。
- [ ] G3：证明 MessageId 提交持久化与崩溃后对账路径。
- [ ] G4：桌面/微信共用 Agent，审批与问题不会双重裁决。
- [ ] G5：验证原生对话与 Trajectory 导航。

## 端到端验收

- [ ] 配对本人、陌生人拒绝、解绑换号后旧任务不得投递。
- [ ] 文本、纯图片、纯文件、混合消息均可处理。
- [ ] 图片下载慢或失败时，后续解释文字不会越过它提交；控制指令仍可处理。
- [ ] 出站文本、原生图片、原生文件与面板记录一致。
- [ ] 文件越界、超限、损坏、磁盘满均有明确行为。
- [ ] 重复批次不重复提交；提交 ACK 丢失后不会重复执行。
- [ ] 结果回放不重复创建 Outbox；发送响应丢失显示待核对。
- [ ] 上下文过期、新消息恢复与发送重试通过。
- [ ] 桌面 turn 不误发微信，不被微信停止指令误取消。
- [ ] 审批并发、超时、Host 重启后的旧请求通过。
- [ ] 面板重开、分页、附件预览/下载、Trace 关联通过。
- [ ] Worker 崩溃、Host 重启、卸载、干净安装与回退通过。
- [ ] 依赖树、源码与产物不存在参考桥接仓库代码。
